# shyai

다양한 커스텀 AI를 개발하는 저장소입니다.
각 AI는 이름별 폴더로 구분되며, 폴더 안에서 버전을 관리합니다.

## 📁 구조

```
shyai/

    └── v<버전>/        # 버전별 작업물
```
