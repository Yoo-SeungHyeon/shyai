# 🧶 Amigurumi

> 캐릭터 사진 한 장으로 나만의 아미구루미 도안을 만드는 AI

**Amigurumi**는 캐릭터 이미지를 입력하면, 코바늘 뜨개질로 직접 만들 수 있는 **아미구루미(Amigurumi) 도안**을 자동으로 생성하는 모델입니다.
좋아하는 캐릭터, 직접 그린 캐릭터, 반려동물 사진 등 원하는 대상을 뜨개 인형으로 만들 수 있도록 돕는 것이 목표입니다.

---

## 📌 목표

- 캐릭터 이미지에서 **형태(몸통·머리·팔·다리·귀 등 파츠)** 를 분석
- 각 파츠를 아미구루미 기본 형태(구, 타원체, 원기둥, 원뿔 등)로 단순화
- 파츠별 **단(Round) 단위 코 수와 늘림/줄임 규칙**을 계산해 도안 생성
- 캐릭터 색상을 분석해 **실 색상 추천 및 색 전환 위치** 표시
- 파츠 **조립 위치와 순서**, 눈·입 등 디테일 표현 방법 안내

## 🔄 동작 흐름

```
[캐릭터 이미지]
      │
      ▼
1. 이미지 전처리      ─ 배경 제거, 캐릭터 영역 추출
      │
      ▼
2. 파츠 분할          ─ 머리 / 몸통 / 팔 / 다리 / 귀 / 꼬리 / 액세서리
      │
      ▼
3. 형태 추정          ─ 파츠별 3D 기본 도형 근사 및 비율 계산
      │
      ▼
4. 색상 분석          ─ 대표 색상 추출 → 실 색상 매칭
      │
      ▼
5. 도안 생성          ─ 단별 코 수, 늘림(inc)/줄임(dec) 패턴 계산
      │
      ▼
6. 출력               ─ 텍스트 도안 + 파츠 다이어그램 + 조립 가이드
```

## 📥 입력 / 📤 출력

### 입력

| 항목 | 설명 | 필수 |
| --- | --- | --- |
| 캐릭터 이미지 | 정면 이미지 권장 (PNG / JPG) | ✅ |
| 완성 크기 | 목표 높이 (예: 10cm, 15cm) | 선택 |
| 실 굵기 / 바늘 호수 | 예: 합사 4ply, 코바늘 3.0mm | 선택 |
| 난이도 | 초급 / 중급 / 고급 (디테일 단순화 정도) | 선택 |

### 출력 예시

```
[머리] 메인 색상: 아이보리
R1 : 매직링에 짧은뜨기 6코 (6)
R2 : 늘림 ×6 (12)
R3 : (짧은뜨기 1, 늘림) ×6 (18)
R4 : (짧은뜨기 2, 늘림) ×6 (24)
R5–R9 : 짧은뜨기 24 (24)
R10 : (짧은뜨기 2, 줄임) ×6 (18)
  → 9~10단 사이, 7코 간격으로 안전눈 부착
R11 : (짧은뜨기 1, 줄임) ×6 (12)
  → 솜 채우기
R12 : 줄임 ×6 (6)
  → 마무리 후 실 정리
```

- 파츠별 단계별 도안 (텍스트 / PDF)
- 필요한 실 색상 및 예상 사용량
- 파츠 조립 위치 다이어그램

## 📖 용어 정리

| 약어 | 영문 | 한글 |
| --- | --- | --- |
| MR | Magic Ring | 매직링 |
| sc | Single Crochet | 짧은뜨기 |
| inc | Increase | 늘림 (한 코에 짧은뜨기 2번) |
| dec | Decrease | 줄임 (두 코를 하나로) |
| R | Round | 단 |
| sl st | Slip Stitch | 빼뜨기 |
| ch | Chain | 사슬뜨기 |
| FLO / BLO | Front / Back Loop Only | 앞/뒤 반코만 뜨기 |

## ⚠️ 참고 사항

- 저작권이 있는 캐릭터로 만든 도안 및 인형은 **개인 소장 용도**로만 사용하는 것을 권장합니다.
- 생성된 도안은 실의 굵기, 손 땀의 세기(텐션)에 따라 결과물 크기가 달라질 수 있습니다.
